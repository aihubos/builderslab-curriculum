  • 준비 / 도움이 필요 / 아직 못함 중 현재 상태를 표시하세요.

UNDERSTAND / CLASS 03

Wiki는 작은 지식 모음이에요

  • 특정 유료 서비스를 설치하는 수업이 아닙니다. 원문 파일, 읽기 쉬운 노트, 노트를 연결하는 목차로 구성합니다. 처음에는 몇 개의 텍스트 파일이면 됩니다.
  • sources/원문 → notes/요약 → index.md/목차

UNDERSTAND / CLASS 03

답과 출처를 함께 남겨요

  • 출처가 실제로 답의 주장을 뒷받침하는지 확인합니다. 자료에 없는 질문은 모른다고 표시하는 것이 정확한 지식 정리입니다.
  • 질문: 참가비는? / 답: 자료에 없음 / 확인: S1 원문

UNDERSTAND / CLASS 03

새 파일이 항상 새 규칙은 아니에요

  • 어느 규칙을 대체한다는 문장이 있는지 확인합니다. 이전 버전을 남기고 현재 적용 내용과 변경 이유를 기록합니다. 파일 이름만으로 우선순위를 단정하지 않습니다.
  • S4가 S1의 파일명 규칙을 대체 → 변경 기록에 근거 S4

  • 지금은 보고, 다음 단계에서 직접 따라 합니다.
