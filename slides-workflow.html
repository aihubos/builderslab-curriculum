UNDERSTAND / CLASS 02

요청을 네 칸으로 나눠요

  • 상황은 지금 가진 자료, 할 일은 수행할 행동, 목적은 결과를 쓸 이유, 제한은 지킬 조건입니다. 수업에서는 이 네 칸을 요청 설계 틀로 씁니다. 명칭보다 내용이 빠졌는지를 봅니다.
  • 상황: 주간 메모 / 할 일: 보고서 / 목적: 다음 행동 공유 / 제한: 없는 날짜 금지

  • 바꾸기: 입력·출력 / 유지하기: 요약·완료·다음 행동·미정

  • 공통: 원문 보존 / 선택: 주간 보고서 / 예약: 언제 실행할지

ANSWER CHECK / CLASS 02

표현은 달라도 이 조건은 같아야 해요

  • 소라는 질문 3개 정리 완료, 다음 행동은 질문 분류이며 마감 미정입니다. 건우는 2개 중 1개 확보한 진행 상태, 나머지 1개는 목요일까지입니다. 공지는 담당·마감 미정, 공유 방식도 미정입니다. 임의의 전체 진척률은 만들지 않습니다.
