01

설치하고, 내 계정으로 들어가요.

할 일

  1. 공식 Windows 설치 안내 ↗를 열고 다운로드 링크로 이동합니다.
  2. 공식 배포 화면의 설치 절차를 진행한 뒤 앱을 엽니다. 관리자가 설치를 제한한 컴퓨터라면 진행자에게 알려주세요.
  3. 본인 ChatGPT 계정으로 로그인하고 Codex를 선택합니다.
  1. 공식 데스크톱 앱 안내 ↗에서 Mac 다운로드와 지원 기종을 확인합니다. 현재 안내의 Mac 다운로드는 Apple Silicon용입니다.
  2. 내 Mac이 지원되는지 확인한 뒤 받은 설치 파일의 안내에 따라 설치하고 앱을 엽니다.
  3. 본인 ChatGPT 계정으로 로그인하고 Codex를 선택합니다.
공식 안내가 ChatGPT 데스크톱 앱으로 표시될 수 있습니다. 해당 앱에서 Codex를 선택하는 방식이며, 버전에 따라 메뉴 이름이 다를 수 있어요. 이미 Codex 앱을 사용 중이면 다시 설치하기 전에 진행자와 확인하세요.

입력 예시

로그인 화면에 본인의 계정 정보를 입력합니다. 비밀번호를 교안이나 대화에 붙여 넣지 않습니다.

정상 결과

내 계정으로 앱이 열리고, Codex 작업을 시작할 수 있습니다.

막혔을 때 ＋

설치 오류는 운영체제와 오류 문구를 기록해 진행자에게 보여주세요. 로그인 오류는 브라우저에 같은 계정으로 로그인되는지 확인하세요. 지원 기종·계정 접근 문제가 있으면 여기서 멈추고 도움을 받습니다. 결제나 추가 권한 승인을 무작정 진행하지 않습니다.

02

연습할 폴더를 만들어요.

할 일

폴더는 파일을 담는 상자예요. 오늘은 실제 업무 폴더 대신 새 연습 폴더를 사용합니다.

  1. 작업 표시줄의 노란 폴더 아이콘으로 파일 탐색기를 엽니다.
  2. 내가 파일을 저장할 수 있는 ‘문서’ 위치로 이동합니다.
  3. 빈 곳에서 마우스 오른쪽 버튼 → 새로 만들기 → 폴더를 선택합니다.
  4. 이름을 codex-practice로 입력하고 Enter를 누릅니다.
  1. Dock의 웃는 얼굴 아이콘으로 Finder를 엽니다.
  2. 사이드바에서 ‘문서’를 엽니다.
  3. 상단 ‘파일’ → ‘새로운 폴더’를 선택합니다.
  4. 이름을 codex-practice로 입력하고 Return을 누릅니다.

입력 예시

codex-practice
정상 결과

문서 위치에 codex-practice 폴더가 있고, 두 번 눌러 빈 폴더를 열 수 있습니다.

막혔을 때 ＋

같은 이름의 폴더가 이미 있으면 내용을 지우지 마세요. codex-practice-2처럼 새 이름을 쓰고, 이후에는 그 폴더를 선택합니다. ‘문서’가 보이지 않으면 진행자와 쓰기 가능한 위치를 정하세요.

03

샘플 메모를 준비해요.

할 일

아래 가상 메모 두 개를 내려받고, 방금 만든 연습 폴더로 복사하세요.

첫 메모 받기 ↓반복용 메모 받기 ↓

파일 탐색기 → 다운로드에서 두 파일을 선택하고 Ctrl + C를 누릅니다. 연습 폴더를 열고 Ctrl + V로 붙여 넣습니다.

Finder → 다운로드에서 두 파일을 선택하고 ⌘ + C를 누릅니다. 연습 폴더를 열고 ⌘ + V로 붙여 넣습니다.

입력 예시 · 첫 메모 내용

모임 연습 메모 1 (가상 자료)
오늘은 다음 모임의 준비 사항을 이야기했다.
민지는 소개 문구 초안을 준비한다. 마감일은 정하지 않았다.
준호는 공개 자료 3개를 찾아온다. 마감일은 정하지 않았다.
다음 모임 날짜와 장소는 아직 정하지 않았다.
정상 결과

연습 폴더 안에 memo-01.txt와 memo-02.txt가 있고, 파일을 열면 한글 메모가 보입니다.

막혔을 때 ＋

브라우저의 다운로드 목록에서 ‘폴더에서 보기’ 또는 이에 해당하는 기능을 사용하세요. 이름에 (1)이 붙었다면 기존 파일과 구분한 후 연습 폴더에 복사한 파일 이름을 memo-01.txt로 맞춥니다. 확장자가 안 보이면 임의로 .txt를 덧붙이지 말고 진행자에게 확인하세요.

04

폴더를 열고, 첫 요청을 보내요.

할 일

  1. Codex에서 프로젝트 추가 또는 폴더 열기 기능으로 codex-practice를 선택합니다. 앱에 보이는 메뉴가 다르면 공식 시작 안내 ↗를 함께 확인하세요.
  2. 그 폴더에서 새 작업을 열고, 아래 요청문을 복사해 입력창에 붙여 넣습니다.
  3. 메시지를 보내고 완료될 때까지 기다립니다. 파일 작업 허용을 요청하면 대상이 내 연습 폴더인지 확인합니다.

입력 예시 · 그대로 복사하세요

첫 정리 요청문
현재 연습 폴더의 memo-01.txt를 읽고 result-01.txt를 새로 만들어줘.
원문 파일은 바꾸지 말아줘. 출력은 다음 순서로 작성해줘.
1. 요약: 핵심 내용 3줄 이내
2. 할 일: 작업 / 담당자 / 마감일
3. 미정 사항: 아직 정하지 않은 내용
원문에 없는 담당자·날짜·장소를 만들지 말고 미정이라고 써줘.
이미 result-01.txt가 있으면 덮어쓰지 말고 다른 이름을 먼저 제안해줘.
연습 폴더 밖의 파일은 변경하지 마. 외부 전송이나 예약 실행은 하지 마.
완료하면 저장한 파일 이름과 위치를 알려줘.
요청문을 파일로 받기 ↓
정상 결과

Codex가 파일 작업을 마치고 저장한 파일 이름과 위치를 알려줍니다. 다음 단계에서 실제 파일을 확인합니다.

막혔을 때 ＋

‘파일을 찾을 수 없다’면 Codex가 연 폴더와 파일 탐색기/Finder의 폴더가 같은지 비교하세요. 계획만 설명하고 실행하지 않으면 “계획한 내용을 연습 폴더 안에서 실행해서 결과 파일을 만들어줘”라고 요청합니다. 접근이 막히면 전체 접근으로 바꾸지 말고 진행자에게 오류 문구를 보여주세요.

05

답변보다, 실제 파일을 확인해요.

할 일

연습 폴더로 돌아가 result-01.txt를 두 번 눌러 엽니다. 이름을 바꿔 저장했다면 Codex가 알려준 파일을 여세요.

앱 선택 창이 뜨면 메모장을 선택하세요.

앱 선택이 필요하면 텍스트 편집기로 여세요.

입력 예시 · 빠진 내용을 고칠 때

수정 요청문
memo-01.txt와 result-01.txt를 비교해줘.
담당자는 민지와 준호이고, 마감일은 둘 다 미정이야.
모임 날짜와 장소도 미정으로 남겨야 해.
틀린 항목만 result-01.txt에서 고치고, 원문은 그대로 두어줘.
정상 결과 · 표현은 달라도 아래 정보는 같아야 해요
첫 메모의 할 일 비교표
작업담당자마감일
소개 문구 초안민지미정
공개 자료 3개 찾기준호미정

요약에는 준비 사항 논의가, 미정 사항에는 모임 날짜·장소가 있어야 합니다. 원문 메모는 바뀌지 않아야 해요.

막혔을 때 ＋

결과가 대화에만 보이면 “대화에 보여준 내용을 연습 폴더의 result-01.txt 파일로 저장해줘”라고 요청하세요. 파일이 안 보이면 저장 위치를 알려달라고 하세요. 다른 이름으로 저장했다면 수정 요청문에도 그 이름을 사용합니다.

06

다른 메모에도 같은 일을 시켜요.

할 일

두 번째 샘플을 사용합니다. 새 요청에서는 입력과 출력 이름만 바꾸고, 정리 규칙은 유지해요.

입력 예시

두 번째 정리 요청문
현재 연습 폴더의 memo-02.txt를 읽고 result-02.txt를 새로 만들어줘.
요약(3줄 이내), 할 일(작업 / 담당자 / 마감일), 미정 사항 순서로 정리해줘.
원문에 없는 담당자·날짜·장소는 만들지 말고 미정으로 써줘.
원문과 result-01.txt는 변경하지 마.
result-02.txt가 이미 있으면 덮어쓰기 전에 다른 파일 이름을 제안해줘.
이 연습 폴더 안에서만 작업하고 외부 전송·예약 실행은 하지 마.
완료하면 저장한 파일 이름과 위치를 알려줘.
정상 결과

새 결과에는 ‘자료 후보 2개 정리 / 수진 / 미정’과 ‘참가 안내문 / 미정 / 미정’이 있어요. 최종 자료와 모임 날짜는 미정입니다. 첫 결과도 그대로 남아 있어야 해요.

막혔을 때 ＋

첫 메모의 민지·준호가 다시 나오면 “이번 입력은 memo-02.txt만 사용해줘”라고 명시하세요. 틀린 입력 파일을 읽었는지 먼저 확인합니다.

07

이제, 내 힘으로 한 번 더.

할 일

  1. Codex를 닫았다가 다시 열고 내 연습 폴더를 찾습니다.
  2. memo-02.txt를 사용하되 결과 이름을 result-03.txt로 바꿉니다.
  3. 이전 요청문을 직접 고쳐 보낸 뒤, 저장된 결과를 열어 확인합니다.

입력 예시 · 이번에는 빈칸을 직접 바꿔요

입력 파일: memo-02.txt
출력 파일: result-03.txt
정리 형식: 요약 / 할 일 / 미정 사항
조건: 원문 보존, 없는 정보는 미정, 기존 결과 덮어쓰기 금지
정상 결과

새 파일을 직접 찾고, 원문과 비교해 수진의 작업과 미정 사항을 설명할 수 있으면 성공입니다. 입력·출력 이름만 바꾸어 같은 작업을 반복하는 방법을 배웠어요.

막혔을 때 ＋

막힌 단계의 체크를 해제하고 그 단계부터 다시 읽어보세요. 결과가 다르다는 것만 말하기보다, 기대한 내용과 실제 내용을 하나씩 비교해서 요청하면 됩니다.

✓
