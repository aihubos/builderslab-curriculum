### 할 일

Finder → 다운로드에서 두 파일을 선택하고 ⌘ + C를 누릅니다. 연습 폴더를 열고 ⌘ + V로 붙여 넣습니다.

### 입력 예시 · 첫 메모 내용
```text
모임 연습 메모 1 (가상 자료)

준호는 공개 자료 3개를 찾아온다. 마감일은 정하지 않았다.
다음 모임 날짜와 장소는 아직 정하지 않았다.
```

정상 결과

막혔을 때 ＋
브라우저의 다운로드 목록에서 ‘폴더에서 보기’ 또는 이에 해당하는 기능을 사용하세요. 이름에 (1)이 붙었다면 기존 파일과 구분한 후 연습 폴더에 복사한 파일 이름을 memo-01.txt로 맞춥니다. 확장자가 안 보이면 임의로 .txt를 덧붙이지 말고 진행자에게 확인하세요. 두 샘플 파일이 연습 폴더에 있어요

## 폴더를 열고, 첫 요청을 보내요.

### 할 일
- Codex에서 프로젝트 추가 또는 폴더 열기 기능으로 codex-practice를 선택합니다. 앱에 보이는 메뉴가 다르면 공식 시작 안내 ↗ (https://learn.chatgpt.com/docs/quickstart)를 함께 확인하세요.
- 그 폴더에서 새 작업을 열고, 아래 요청문을 복사해 입력창에 붙여 넣습니다.
- 메시지를 보내고 완료될 때까지 기다립니다. 파일 작업 허용을 요청하면 대상이 내 연습 폴더인지 확인합니다.

### 입력 예시 · 그대로 복사하세요

첫 정리 요청문요청문 복사
```text
현재 연습 폴더의 memo-01.txt를 읽고 result-01.txt를 새로 만들어줘.
원문 파일은 바꾸지 말아줘. 출력은 다음 순서로 작성해줘.
1. 요약: 핵심 내용 3줄 이내
2. 할 일: 작업 / 담당자 / 마감일
3. 미정 사항: 아직 정하지 않은 내용
원문에 없는 담당자·날짜·장소를 만들지 말고 미정이라고 써줘.
이미 result-01.txt가 있으면 덮어쓰지 말고 다른 이름을 먼저 제안해줘.
연습 폴더 밖의 파일은 변경하지 마. 외부 전송이나 예약 실행은 하지 마.
완료하면 저장한 파일 이름과 위치를 알려줘.
```
요청문을 파일로 받기 ↓
정상 결과
Codex가 파일 작업을 마치고 저장한 파일 이름과 위치를 알려줍니다. 다음 단계에서 실제 파일을 확인합니다.
막혔을 때 ＋
‘파일을 찾을 수 없다’면 Codex가 연 폴더와 파일 탐색기/Finder의 폴더가 같은지 비교하세요. 계획만 설명하고 실행하지 않으면 “계획한 내용을 연습 폴더 안에서 실행해서 결과 파일을 만들어줘”라고 요청합니다. 접근이 막히면 전체 접근으로 바꾸지 말고 진행자에게 오류 문구를 보여주세요. 첫 요청을 보내고 작업 완료 응답을 받았어요
