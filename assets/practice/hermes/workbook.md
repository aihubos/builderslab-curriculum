# 내 컴퓨터에서 시작하는 메모 정리 비서

Hermes Desktop을 설치하고 기존 ChatGPT/Codex 구독을 연결해 같은 규칙으로 메모 두 개를 처리합니다.

## 먼저 확인

01·02 완료 권장. 개인 Windows 또는 Apple Silicon Mac, 인터넷, 본인 구독 계정을 준비하세요. 계정 연결이 확인되어야 AI 실습을 진행할 수 있어요.

## 준비

ZIP 압축을 풀고 START-HERE.txt가 보이는 폴더를 작업 폴더로 엽니다. AI 작업은 본인 앱에서 실행합니다.

## 01. 내 컴퓨터와 사용할 계정을 확인해요

### 할 일

1. Hermes는 비서 프로그램이고 연결하는 AI 모델은 답을 만드는 엔진입니다. 프로그램 설치와 계정 연결을 따로 확인합니다.

2. 아래 운영체제별 방법으로 기종을 확인하고 설치 공식 안내의 지원 범위를 대조합니다.

3. 본인 ChatGPT/Codex 계정으로 이미 사용 가능한지 확인합니다. 이용 가능 여부와 한도는 로그인 화면 및 서비스 안내가 기준입니다.

### Windows

설정 → 시스템 → 정보에서 Windows 버전과 시스템 종류를 확인합니다. 공식 Platform Support의 Windows 항목과 비교하세요.

### Mac

왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 칩을 봅니다. 공식 Mac 설치 파일은 Apple Silicon용입니다. Intel Mac은 이 설치 경로를 지원하지 않습니다.

### 입력 예시

```text

준비 메모 (직접 채우세요)
운영체제:
칩 또는 프로세서:
기존 ChatGPT/Codex 이용 가능: 예 / 확인 필요
실습할 일: 가상 모임 메모 정리
외부 발송·메신저·예약 연결: 이번에는 안 함

```

### 정상 결과

지원 환경과 본인 계정을 확인했습니다. Mac Intel이면 이 교재의 Desktop 설치 경로로 진행하지 않습니다.

### 막혔을 때

지원되지 않는 기기라면 진행자에게 다른 실습 기기를 요청하세요. 설치가 된 것과 AI가 응답하는 것은 별개입니다.

- [ ] 지원 기종과 계정을 확인했어요

## 02. 공식 Desktop 설치 파일로 설치해요

### 할 일

1. 교재 아래 공식 설치 안내를 열고 그 페이지의 Desktop Download 링크를 사용합니다. 광고 검색 결과에서 설치하지 않습니다.

2. 현재 컴퓨터에 맞는 설치 파일을 내려받고 열어 설치 화면 안내를 따릅니다.

3. Hermes Desktop을 실행합니다. 이미 설치되어 있다면 재설치하지 않고 기존 앱을 여세요.

### Windows

다운로드 폴더에서 Windows용 설치 파일을 엽니다. 보이는 설치 안내를 따른 뒤 시작 메뉴에서 Hermes를 찾아 실행하세요. 관리자 설치 제한이 있으면 진행자에게 알립니다.

### Mac

다운로드 폴더에서 Mac용 설치 파일을 엽니다. 디스크 이미지라면 표시된 안내에 따라 응용 프로그램으로 옮긴 후 Hermes를 실행합니다. 설치 형식이 다르면 해당 설치 화면의 지시를 따릅니다.

### 입력 예시

```text

이 단계는 AI 요청이 아닙니다.
공식 주소: https://hermes-agent.nousresearch.com/docs/getting-started/installation
그 페이지의 Hermes Desktop 다운로드 링크 → 내 운영체제 파일 → 설치 → Hermes Desktop 실행

```

### 정상 결과

Hermes Desktop 창이 열립니다. 아직 답변을 받지 못해도 설치 단계는 확인할 수 있습니다.

### 막혔을 때

다운로드 차단·서명 경고를 우회하지 말고 공식 파일인지 진행자와 확인합니다. 화면이 교재와 다르면 문구를 기록하세요. 이 교재는 실제 설치 화면을 재현한 그림을 사용하지 않습니다.

- [ ] Hermes Desktop 창을 열었어요

## 03. 기존 구독 계정을 연결해요

### 할 일

1. Hermes 설정의 모델 연결에서 ChatGPT/Codex 구독 항목을 찾습니다. 화면 구성이 다르면 아래 공식 명령 방식으로 설정할 수 있습니다.

2. 명령 방식: Windows는 시작 메뉴에서 PowerShell, Mac은 Spotlight에서 터미널을 열고 아래 한 줄을 입력합니다.

3. hermes model 목록에서 ChatGPT or Codex Subscription에 해당하는 항목을 선택합니다. 표시된 공식 인증 페이지를 열고 본인 계정으로 기기 코드 인증을 완료합니다.

4. Hermes로 돌아와 사용 가능한 모델을 선택합니다. 인증 코드와 비밀번호는 Codex나 다른 사람에게 보내지 않습니다.

### 입력 예시

```text

hermes model

```

### 정상 결과

설정에서 선택한 제공자·모델이 표시되고 인증 오류가 없어집니다. 모델 이름은 현재 계정에 표시되는 목록에서 선택하며 교재가 임의로 고정하지 않습니다.

### 막혔을 때

명령을 찾지 못하면 터미널을 닫고 다시 열어봅니다. 계속 안 되면 앱 설치 경로를 진행자와 확인하세요. 구독 항목이 없거나 인증이 거부되면 결제·API 발급으로 우회하지 말고 공식 안내와 계정 지원 여부를 확인합니다.

- [ ] 본인 구독 연결과 모델 선택을 확인했어요

## 04. 도구 없이 짧은 응답부터 받아요

### 할 일

1. Hermes에서 새 대화를 엽니다. 이제 입력하는 곳은 Codex가 아니라 Hermes입니다.

2. 아래 요청을 보냅니다. 파일 작업 전에 모델이 응답하는지만 확인하세요.

### 입력 예시

```text

도구를 실행하지 말고 한국어로 “메모 정리 준비 완료”라고 한 문장만 답해줘.

```

### 정상 결과

짧은 한국어 응답을 받습니다. 이 결과는 모델 연결 성공 확인이며 파일 저장 성공 확인은 아닙니다.

### 막혔을 때

Unauthorized/인증 오류는 계정 연결을, 사용량 초과는 계정 한도를 확인합니다. 연결 오류에서 같은 요청을 계속 보내지 말고 설정의 제공자·모델을 먼저 확인하세요.

- [ ] Hermes에서 첫 응답을 받았어요

## 05. 메모 비서의 연습 폴더를 열어요

### 할 일

1. 위의 실습 꾸러미 ZIP을 내려받습니다. ZIP은 여러 파일을 담은 포장 상자입니다. 압축을 풀어야 파일을 바꿀 수 있어요.

2. 문서에 practice-과정이름 폴더를 만들고 압축을 푼 파일들을 넣습니다. START-HERE.txt가 바로 보이는 위치를 찾으세요.

3. Codex에서 그 폴더를 프로젝트로 열고 새 작업을 만듭니다. 01 과정의 폴더 열기 단계가 낯설면 먼저 돌아가 연습하세요.

4. 아래 요청을 보내 파일 목록을 확인합니다. 이번에는 파일을 수정하지 않습니다.

5. 이번 과정 폴더 이름은 practice-hermes로 둡니다.

6. Codex에는 폴더 준비만 맡기고, 아래 안내대로 해당 폴더에서 Hermes를 엽니다. 이후 AI 요청은 Hermes에 보냅니다.

### Windows

ZIP에서 마우스 오른쪽 버튼 → 모두 압축 풀기. 풀린 폴더를 문서로 복사하세요. 파일 탐색기에서 START-HERE.txt가 있는지 확인합니다. ZIP 안을 바로 열어 작업하지 마세요.

### Mac

Finder의 다운로드에서 ZIP을 두 번 누르면 폴더가 생깁니다. 그 폴더를 문서로 옮기세요. Finder에서 START-HERE.txt가 있는지 확인합니다.

### 입력 예시

```text

Codex에 요청:
현재 폴더가 START-HERE.txt, assistant-rules.txt, input/memo-01.txt가 있는 practice-hermes 연습 폴더인지 확인해줘.
설치된 hermes 명령의 위치를 확인하고, 공식 hermes desktop --cwd 명령으로 이 폴더를 작업 폴더로 하는 Desktop을 열어줘.
설치나 계정 설정은 바꾸지 마. 명령이 없으면 멈추고 알려줘.

Hermes에서 확인:
현재 작업 폴더의 경로와 assistant-rules.txt, input/memo-01.txt가 있는지만 알려줘. 파일을 수정하지 마.

```

### 정상 결과

Hermes가 알려준 폴더 경로가 내 연습 폴더입니다. input 파일 두 개와 assistant-rules.txt를 읽을 수 있습니다.

### 막혔을 때

다른 폴더면 작업을 진행하지 않습니다. 공식 명령은 hermes desktop --cwd 뒤에 실제 폴더 경로를 따옴표로 감싼 형태입니다. Codex에 정확한 실행 명령을 보여달라고 요청하세요. 이미 열린 앱이 다른 폴더를 유지하면 닫고 다시 실행합니다.

- [ ] Hermes의 작업 폴더와 파일을 확인했어요

## 06. 비서의 규칙을 읽히고 첫 파일을 만들어요

### 할 일

1. assistant-rules.txt를 직접 읽습니다. 말투보다 입력·출력·하지 않을 일이 먼저입니다.

2. 아래 요청을 Hermes에 보냅니다. 작업 허용을 묻는다면 대상이 연습 폴더인지 확인하세요.

3. 완료 후 파일 탐색기/Finder에서 output/hermes-01.md를 열어봅니다.

### 입력 예시

```text

assistant-rules.txt를 읽고 이번 작업에 적용해줘.
입력은 input/memo-01.txt 하나, 출력은 output/hermes-01.md야.
요약 3줄 이내 / 할 일 표 / 미정 사항 / 근거 파일 순서로 정리해줘.
원문과 기존 결과 보존, 미정은 추측 금지. output이 없으면 만들어줘.
작업 범위는 현재 연습 폴더, 외부 발송·예약·다른 에이전트 호출 없음.
실제로 저장한 파일 경로를 알려줘.

```

### 정상 결과

민지=소개 문구, 준호=공개 자료 3개, 두 마감일 미정입니다. 날짜·장소도 미정이고 실제 파일이 있습니다.

### 막혔을 때

“저장했다”는 답만 믿지 말고 실제 파일을 확인하세요. 쓰기 도구가 실패했다면 오류를 확인하고 폴더 접근 문제부터 해결합니다.

- [ ] 비서가 만든 첫 결과 파일을 직접 열었어요

## 07. 같은 메모를 다시 처리해 비교해요

### 할 일

1. 같은 입력으로 두 번째 결과를 만듭니다.

2. 문장 표현이 똑같은지를 보지 말고 사람·작업·미정 정보가 같은지 비교합니다.

### 입력 예시

```text

assistant-rules.txt를 다시 읽고 input/memo-01.txt를 output/hermes-01-repeat.md로 정리해줘.
이전 결과를 복사하지 말고 입력을 다시 읽어줘. 기존 파일은 보존해줘.
output/hermes-01.md와 새 결과의 담당자·작업·마감일 차이를 표로 보여줘.

```

### 정상 결과

표현이 달라도 핵심 정보는 같아야 합니다. 한쪽에 구체적 날짜가 생겼다면 원문을 대조해 수정합니다.

### 막혔을 때

두 번 결과가 다르면 규칙에 빠진 부분 한 가지를 보완합니다. “항상 똑같이 해”보다 “없는 마감일은 미정”이 분명합니다.

- [ ] 두 실행의 핵심 정보가 같은지 비교했어요

## 08. 새 대화에서도 같은 비서로 사용해요

### 할 일

1. Hermes에서 새 대화를 열어 이전 대화가 없어도 실행할 수 있는지 봅니다.

2. 규칙 파일과 새 입력 이름을 다시 명시합니다. 파일 규칙이 새 대화에 저절로 적용된다고 가정하지 않습니다.

### 입력 예시

```text

이번 대화도 assistant-rules.txt를 읽고 적용해줘.
input/memo-02.txt만 읽어 output/hermes-02.md에 정리해줘.
기존 파일은 변경하지 마. 완료 후 expected/checklist.txt와 대조해서 정보가 맞는지 알려줘.

```

### 정상 결과

수진/자료 후보 2개/미정, 안내문/담당자 미정/마감일 미정입니다. 민지·준호를 이번 결과에 넣지 않습니다.

### 막혔을 때

잘못된 입력이 섞이면 새 대화의 작업 폴더를 먼저 확인합니다. 비서 지침을 읽었는지 파일 경로와 함께 묻습니다.

- [ ] 새 대화에서 다른 메모를 처리했어요

## 09. 일부러 파일을 못 찾게 해봐요

### 할 일

1. 존재하지 않는 입력을 지정해 실패 처리 방식을 확인합니다.

2. 비서가 없는 내용을 만들지 않고 멈추는지 확인합니다.

### 입력 예시

```text

assistant-rules.txt 기준으로 input/not-exist.txt를 정리해줘.
파일이 없으면 만들거나 내용을 추측하지 말고 파일을 찾지 못했다고 알려줘.
출력 파일은 만들지 마.

```

### 정상 결과

파일을 찾지 못했다는 안내가 나오고 결과 파일이 생기지 않습니다.

### 막혔을 때

없는 파일을 만들어버렸다면 새 파일을 별도로 보관하고 규칙 위반을 기록하세요. 원본을 삭제하며 복구하려 하지 않습니다.

- [ ] 실패할 때 멈추는지 확인했어요

## 10. 다시 쓰는 방법을 내 말로 남겨요

### 할 일

1. 정상 실행으로 돌아와 input/memo-02.txt → output/hermes-03.md를 혼자 요청합니다.

2. 사용한 계정 종류·모델 이름·폴더·성공 기준·실패 시 확인 순서를 적습니다. 비밀 값은 적지 않습니다.

3. 예약·메신저 연결은 별도 확장입니다. 이 수업의 완료는 내 컴퓨터에서 작업 하나를 반복하는 것입니다.

### 입력 예시

```text

이번에는 input/memo-02.txt를 output/hermes-03.md로 정리해줘. assistant-rules.txt를 먼저 읽어줘.
이후 HOW-TO.md에 앱 열기 → 모델 연결 확인 → 연습 폴더 확인 → 규칙과 입력 지정 → 결과 파일 확인 순서를 적어줘.
오류는 설치/모델 인증/폴더 접근/결과 내용 중 어디인지 구분하도록 적어줘.
비밀번호·인증 코드·토큰은 기록하지 마.

```

### 정상 결과

세 번째 파일과 재사용 안내가 있습니다. 연결 실패 시 설치를 무작정 다시 하는 대신 어느 단계 문제인지 설명합니다.

### 막혔을 때

한 번에 여러 설정을 바꾸지 않습니다. 짧은 응답이 되는지부터 확인한 뒤 파일 작업으로 돌아옵니다.
