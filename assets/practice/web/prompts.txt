01 실습 꾸러미와 작업 폴더 준비
지금 열린 연습 폴더의 경로와 파일 목록만 알려줘. 아직 파일을 수정하지 마.
확인할 파일: profile.txt, revision.txt

02 누구에게 무엇을 보여줄지 정해요
profile.txt를 읽고 한 페이지 구성안을 설명해줘.
순서는 소개 → 관심사 3개 → 첫 작업 → 같은 페이지 안 이동 버튼이야.
제공되지 않은 연락처·경력·가격·후기·외부 주소는 만들지 마.
코드 작성 전에 각 영역에서 보여줄 문장과 버튼의 목적만 알려줘.

03 내 첫 페이지를 만들어달라고 해요
profile.txt에 있는 내용만 사용해 output/index.html을 만들어줘.
CSS를 HTML 안에 넣은 한 파일로 만들고, 외부 라이브러리·이미지·글꼴 요청은 넣지 마.
흰색과 짙은 남색을 기본으로, 네온 라임을 버튼과 강조에만 사용해줘. 밝은 배경 글자는 어둡게.
소개, 관심사 3개, 첫 작업 소개(id=work)를 넣어줘. 버튼은 href="#work"로 이동하게 해줘.
390px에서는 한 열, PC에서는 여백 있는 카드로. 키보드 초점이 보여야 해.
기존 파일이 있으면 덮어쓰기 전에 알려줘. 인터넷에 올리지 마.

04 파일을 실제 브라우저로 열어요
output/index.html을 내가 볼 수 있도록 브라우저로 열어줘.
열 수 없으면 파일의 실제 위치와 수동으로 여는 방법을 알려줘.
화면을 열었다는 말과 실제 화면 표시를 구분해서 알려줘.

05 버튼을 누르고 Tab으로 이동해요
확인할 동작: 첫 작업 보기 버튼을 누르면 #work로 이동해야 해.
Tab으로 버튼에 도달하고 Enter로 실행되어야 하며 초점 표시가 보여야 해.
현재 HTML의 링크와 id를 확인해서 필요한 부분만 고쳐줘. 문구와 다른 영역은 유지해줘.

06 휴대폰 너비에서 읽어봐요
390px에서 한 열로 배치되고 긴 글도 화면 밖으로 나가지 않게 점검해줘.
버튼 터치 영역은 충분히 크게, 본문은 읽기 쉬운 크기로 유지해줘.
768px와 1440px에서도 내용이 가려지지 않게 해줘. 수정 전 output/index.html을 backup/index-before-mobile.html로 복사해줘.

07 한 줄만 바꾸고 다시 열어요
output/index.html을 backup/index-before-copy.html로 복사해줘. 같은 백업이 있으면 새 이름을 써줘.
revision.txt의 문장으로 한 줄 소개만 바꿔줘.
관심사·이름·링크·스타일은 그대로 유지하고 바뀐 문장을 보여줘.

08 백업을 다른 이름으로 복원해요
backup/index-before-copy.html을 output/restored.html로 복사해줘.
현재 output/index.html은 유지해줘. 두 파일의 소개 문구 차이를 알려줘.

09 내 소개로 혼자 다시 만들어봐요
my-profile.txt만 사용해서 output/my-page.html을 만들어줘.
단일 HTML, 소개·관심사·작업·같은 페이지 이동 링크, 390px 한 열, 키보드 초점 표시.
제공되지 않은 경력·연락처는 추가하지 마. 기존 예제는 유지하고 인터넷에 배포하지 마.
내가 문구를 바꾸는 위치와 여는 방법을 HOW-TO.md에 남겨줘.
