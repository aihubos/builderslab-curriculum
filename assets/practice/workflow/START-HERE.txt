AI 빌더스랩 workflow 실습 꾸러미
이 자료는 교재를 위해 직접 만든 가상 예제입니다.
1. ZIP 압축을 풀고 이 파일이 보이는 폴더를 Codex 프로젝트로 엽니다.
2. 교재의 단계 순서대로 input 또는 sources를 읽고 output에 결과를 만듭니다.
3. expected는 정답 비교용입니다. 먼저 직접 해본 뒤 열어보세요.
4. 파일 이름을 바꾸면 요청문에도 같은 이름을 써주세요.
5. 요청문은 prompts.txt, 수업 안내는 workbook.md에 있습니다.
기존 결과나 실제 업무 파일을 덮어쓰지 않습니다.
