# Codex로 작은 앱 만들기 · 수강생 공유용

버튼이 동작하고 새로 열어도 기록이 남는 나만의 도구

## 오늘의 목표

- 입력·처리·저장·표시의 흐름을 설명한다.

- 추가·완료·삭제에서 중복과 취소를 확인한다.

- 같은 주소에서 저장을 확인하고 사용법을 남긴다.

## 준비

홈페이지의 파일 열기·수정·Tab 확인을 마칩니다. Python 3와 run-server.py로 고정 로컬 주소를 여는지 사전 확인합니다.

### 화면 뒤에 데이터가 있어요

id: a1 / title: 메모 정리 / done: false

### 저장 위치에는 범위가 있어요

같은 127.0.0.1:8765 → 재열기 / 다른 포트 → 별도 공간

### 실패 상황도 같이 확인해요

빈칸: 추가 안 함 / 취소: 유지 / 새로고침: 상태 유지

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

output에 index.html, style.css, app.js로 할 일 앱을 만들어줘. 외부 라이브러리는 사용하지 마.
처음은 빈 목록. 입력 1~120자, 공백만 있거나 120자를 넘으면 이유를 안내하고 추가하지 마.
추가 버튼과 Enter, 항목별 완료 체크와 삭제 확인/취소를 제공해줘.
각 항목에 고유 id를 주고 같은 문장도 별도로 처리해줘.
localStorage 키는 my-todo-practice-v1. 읽은 데이터의 형식 확인과 저장 실패 안내를 넣어줘.
손상된 저장 데이터는 자동으로 지우거나 덮어쓰지 말고 오류를 알린 뒤 읽기 전용 상태로 멈춰줘.
사용자 입력은 HTML로 해석하지 말고 문자로 표시해줘.
390px 한 열, 긴 문장 줄바꿈, label과 키보드 초점 표시. 기존 파일은 덮어쓰기 전에 알려줘.
온라인 공개나 계정 기능은 추가하지 마.

```

## 결과 확인

- 할 일을 추가·완료·삭제할 수 있다.

- 빈 입력과 긴 내용을 처리한다.

- 새로고침 뒤에도 같은 브라우저에서 기록이 남는다.

## 혼자 해보기

다른 사람이 다시 쓸 수 있는 앱

빈 목록인 연습용 앱에서 challenge.txt 순서로 검사합니다. 기존 내 기록이 있다면 지우지 말고 별도 연습 주소를 준비합니다. 문제 한 곳을 수정한 뒤 같은 검사를 반복합니다.

```text

할 일 앱 독립 확인
입력: 복습하기 / 복습하기 / 자료 정리하기
첫 번째 복습하기만 완료
두 번째 복습하기 삭제 후 취소
자료 정리하기 삭제 후 확인
새로고침 후 상태 확인
빈칸과 <b>메모</b>도 입력해보기.

```
