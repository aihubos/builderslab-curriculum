# Codex로 문서·자료·반복 업무 다루기 · 수강생 공유용

한 번 잘된 요청을 다음 업무에서도 다시 쓰는 작업 방식

## 오늘의 목표

- 일의 상황·할 일·목적·제한을 구분해 요청을 작성한다.

- 틀린 보고서의 사실 오류를 근거와 함께 수정한다.

- 템플릿과 프로젝트 규칙을 남겨 새 자료에도 적용한다.

## 준비

첫걸음의 파일 열기·결과 확인을 혼자 해봅니다. ZIP을 풀어 input, templates, expected 폴더를 확인합니다.

### 요청을 네 칸으로 나눠요

상황: 주간 메모 / 할 일: 보고서 / 목적: 다음 행동 공유 / 제한: 없는 날짜 금지

### 템플릿은 형식을 고정해요

바꾸기: 입력·출력 / 유지하기: 요약·완료·다음 행동·미정

### 공통 규칙과 선택 작업을 구분해요

공통: 원문 보존 / 선택: 주간 보고서 / 예약: 언제 실행할지

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

input/week-01.txt만 읽고 templates/report-template.md 형식의 output/week-01.md를 만들어줘.
원문에 없는 정보는 미정으로 쓰고 요일을 임의의 날짜로 바꾸지 마.
완료한 일과 다음 할 일을 구분해줘. 입력·템플릿·expected는 수정하지 마.
output 폴더가 없으면 만들어줘. 같은 이름이 있으면 덮어쓰지 말고 알려줘.
완료 후 실제 저장 경로를 알려줘.

```

## 결과 확인

- 같은 템플릿으로 두 문서를 처리한다.

- 결과에 빠진 항목을 찾아 요청을 수정한다.

- 수동 실행과 예약 실행의 차이를 설명한다.

## 혼자 해보기

세 번째 주간 보고서

기존 템플릿으로 완료·진행 중·다음 행동·미정 사항을 나눈 보고서를 만드세요. 없는 비율이나 날짜를 덧붙이지 않습니다.

```text

가상 주간 메모 3
소라는 질문 3개 정리를 완료했다. 다음에는 질문을 분류한다. 마감일은 미정이다.
건우는 공개 예시 2개 중 1개를 찾았다. 나머지 1개는 목요일까지 찾는다.
공지 발송은 필요하지만 담당자와 마감일은 정하지 않았다.
최종 공유 방식은 아직 정하지 않았다.

```

## 복습

반복 업무 하나의 입력·출력·확인 기준을 한 줄씩 적습니다. 서로 다른 입력 두 개에 적용한 뒤 유지한 규칙과 바꾼 값을 비교합니다.
