# LLM Wiki로 나의 자료 정리하기 · 수강생 공유용

답의 근거까지 돌아갈 수 있는 작은 자료 정리

## 오늘의 목표

- 원문·요약·내 생각을 분리해 보관한다.

- 답의 출처 파일을 직접 열어 근거를 확인한다.

- 다른 버전의 규칙을 비교하고 변경 이력을 남긴다.

## 준비

텍스트 파일을 저장하고 다시 열 수 있어야 합니다. sources의 가상 자료 세 개를 읽고 어느 파일의 주장인지 구분합니다.

### Wiki는 작은 지식 모음이에요

sources/원문 → notes/요약 → index.md/목차

### 답과 출처를 함께 남겨요

질문: 참가비는? / 답: 자료에 없음 / 확인: S1 원문

### 새 파일이 항상 새 규칙은 아니에요

S4가 S1의 파일명 규칙을 대체 → 변경 기록에 근거 S4

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

sources/01-rules.txt를 읽고 notes/rules.md를 만들어줘.
형식: 핵심 사실 3개 / 내 해석(아직 없음) / 모르는 점 / 원문 링크.
사실마다 S1의 항목 번호를 붙여줘. 원문 링크는 ../sources/01-rules.txt야.
모임 장소나 회비는 추측하지 마. sources는 수정하지 마.

```

## 결과 확인

- 원문과 요약을 각각 보관한다.

- 질문에 답한 노트에서 출처로 돌아갈 수 있다.

- 자료 하나를 추가하고 관련 노트를 갱신한다.

## 혼자 해보기

바뀐 규칙, 남아 있는 미정

challenge.txt를 S5로 등록하고 현재 규칙·목차·변경 이력을 갱신하세요. 현재 파일 이름, 원문 보존, 참가비 질문에 출처를 붙여 답합니다.

```text

S5 추가 안내 (가상 자료)
이 안내는 S4의 결과 파일 이름 규칙만 대체한다.
앞으로 결과 이름은 practice-01.txt, practice-02.txt처럼 사용한다.
원문 보존 규칙은 바꾸지 않는다.
모임 장소와 참가비는 이 안내에서 정하지 않는다.

```

## 보여줄 결과

- sources/S5.txt: 새 원문 사본

- challenge-answer.md: 질문 세 개와 출처

- change-log.md: 바뀐 규칙과 유지한 규칙

## 복습

공개 문서 하나를 추가해 이전 노트와 연결합니다. 답할 수 있는 질문 하나와 없는 질문 하나를 만들어 근거를 확인합니다.
