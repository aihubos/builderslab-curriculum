# Codex로 나만의 홈페이지 만들기 · 수강생 공유용

나를 설명하는 한 페이지를 만들고 직접 수정하는 경험

## 오늘의 목표

- 방문자와 페이지 목적을 한 문장으로 정한다.

- 제공한 사실만으로 소개 페이지를 만들고 링크를 확인한다.

- 세 너비·키보드·수정을 확인하고 백업을 복원한다.

## 준비

Codex에서 폴더를 열 수 있어야 합니다. Chrome 또는 Edge에서 주소창·새로고침 위치를 확인합니다.

### 첫 화면은 한 가지를 말해요

방문자: 모임원 / 알릴 것: 학습 주제 / 행동: 작업 보기

### 좁은 화면에서도 읽혀야 해요

1440px: 나란히 / 768px: 여유 있게 / 390px: 한 열

### 만들기·수정·복원은 한 세트예요

백업 → 한 줄 변경 → 새로고침 → 이전 파일 비교

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

profile.txt에 있는 내용만 사용해 output/index.html을 만들어줘.
CSS를 HTML 안에 넣은 한 파일로 만들고, 외부 라이브러리·이미지·글꼴 요청은 넣지 마.
흰색과 짙은 남색을 기본으로, 네온 라임을 버튼과 강조에만 사용해줘. 밝은 배경 글자는 어둡게.
소개, 관심사 3개, 첫 작업 소개(id=work)를 넣어줘. 버튼은 href="#work"로 이동하게 해줘.
390px에서는 한 열, PC에서는 여백 있는 카드로. 키보드 초점이 보여야 해.
기존 파일이 있으면 덮어쓰기 전에 알려줘. 인터넷에 올리지 마.

```

## 결과 확인

- 소개·본문·이동 링크가 있는 페이지를 연다.

- 모바일 너비에서 글자와 버튼을 확인한다.

- 문구 한 줄을 혼자 수정하고 다시 연다.

## 혼자 해보기

모임원을 위한 두 번째 소개 페이지

challenge.txt로 새 소개를 만드세요. 한 줄을 바꾸기 전 백업하고 수정본과 복원본을 보존합니다. 390·768·1440px에서 확인합니다.

```text

가상 프로필: 다온
한 줄 소개: 작은 기록을 모아 새로운 시도를 합니다.
관심사: 메모 정리, 자료 읽기, 웹 만들기
작업: 오늘 만든 메모 요약, 나의 첫 소개 페이지
방문자: 처음 만난 모임원
버튼: 같은 페이지의 작업 섹션으로 이동
연락처·경력·수상은 제공하지 않음.

```
