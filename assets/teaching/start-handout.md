# Codex 첫걸음과 첫 자동화 · 수강생 공유용

메모 한 장을 맡기고, 결과 파일을 직접 확인하는 첫 경험

## 오늘의 목표

- 입력 파일과 저장할 파일을 구분해 요청할 수 있다.

- 원문에 없는 담당자·날짜를 찾아 미정으로 고칠 수 있다.

- 새 메모와 새 파일 이름으로 같은 작업을 혼자 반복할 수 있다.

## 준비

수업 전 45분 설치 도움 시간을 권장합니다. 본인 기기에서 Codex 로그인과 연습 폴더 열기까지 확인합니다. 미완료자는 교재 01단계를 진행자와 먼저 수행합니다.

### 대화와 파일은 달라요

memo-01.txt → 요청 → result-01.txt → 실제 파일 확인

### 빠른 답도 원문과 비교해요

원문: 마감일은 정하지 않았다 / 결과: 마감일 미정

### 반복할 규칙을 남겨요

첫 번째: memo-01 → result-01 / 두 번째: memo-02 → result-02

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

현재 연습 폴더의 memo-01.txt를 읽고 result-01.txt를 새로 만들어줘.
원문 파일은 바꾸지 말아줘. 출력은 다음 순서로 작성해줘.
1. 요약: 핵심 내용 3줄 이내
2. 할 일: 작업 / 담당자 / 마감일
3. 미정 사항: 아직 정하지 않은 내용
원문에 없는 담당자·날짜·장소를 만들지 말고 미정이라고 써줘.
이미 result-01.txt가 있으면 덮어쓰지 말고 다른 이름을 먼저 제안해줘.
연습 폴더 밖의 파일은 변경하지 마. 외부 전송이나 예약 실행은 하지 마.
완료하면 저장한 파일 이름과 위치를 알려줘.

```

## 결과 확인

- 샘플 메모로 만든 결과 파일을 직접 열 수 있다.

- 없는 담당자·날짜를 만들지 않았는지 확인한다.

- 다른 메모에도 같은 요청문을 바꿔 사용한다.

## 혼자 해보기

처음 보는 세 번째 메모

challenge.txt로 새 결과를 만드세요. 처음 요청부터 입력·출력·형식·제한을 직접 적습니다. 기존 메모와 결과는 보존합니다.

```text

모임 연습 메모 3 (가상 자료)
유나는 다음 모임의 질문 3개를 적어오기로 했다. 마감일은 정하지 않았다.
태오는 공개 예시 1개를 금요일까지 찾아오기로 했다.
참가 안내문은 필요하지만 담당자를 정하지 않았다.
다음 모임의 날짜와 장소는 정하지 않았다.

```
