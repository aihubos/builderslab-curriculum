# Hermes로 나만의 AI 비서 시작하기 · 수강생 공유용

내 컴퓨터의 폴더에서 정해진 일 하나를 수행하는 비서

## 오늘의 목표

- 설치·모델 인증·파일 작업 성공을 따로 확인한다.

- 작업 폴더와 규칙을 명시해 비서를 실행한다.

- 새 대화에서도 반복하고 없는 입력에는 멈추게 한다.

## 준비

별도 45~60분 설치 도움 시간을 권장합니다. 공식 지원 기종·Desktop 실행·기존 ChatGPT/Codex 구독 인증·짧은 응답을 사전 확인합니다. 실패 시 관찰 실습 후 설치를 보충합니다.

### 비서와 엔진은 달라요

앱 실행 → 계정 연결 → 짧은 응답 → 실제 파일

### 일의 범위를 함께 정해요

읽기: input/ / 저장: output/ / 하지 않을 일: 원문 수정·발송

### 새 대화에서도 다시 실행해요

새 대화 → 규칙 읽기 → 입력 존재 → 새 결과 이름

## 대표 실습 요청

앞 단계의 설치·폴더 준비를 마친 후 사용합니다.

```text

assistant-rules.txt를 읽고 이번 작업에 적용해줘.
입력은 input/memo-01.txt 하나, 출력은 output/hermes-01.md야.
요약 3줄 이내 / 할 일 표 / 미정 사항 / 근거 파일 순서로 정리해줘.
원문과 기존 결과 보존, 미정은 추측 금지. output이 없으면 만들어줘.
작업 범위는 현재 연습 폴더, 외부 발송·예약·다른 에이전트 호출 없음.
실제로 저장한 파일 경로를 알려줘.

```

## 결과 확인

- 입력과 출력 범위가 분명한 비서 지침을 만든다.

- 샘플 메모 하나의 처리 결과를 확인한다.

- 실패했을 때 멈추고 재시도하는 순서를 남긴다.

## 혼자 해보기

새 대화의 메모 비서

새 대화에서 규칙을 읽히고 challenge.txt를 처리하세요. 다음에는 없는 missing-challenge.txt를 요청해 결과를 만들지 않고 멈추는지 확인합니다.

```text

비서 실습 메모 3 (가상 자료)
세나는 다음 모임 질문 2개를 수요일까지 적는다.
현우는 공개 예시를 찾는다. 마감일은 정하지 않았다.
공유 파일 정리는 필요하지만 담당자는 정하지 않았다.
모임 날짜는 미정이다.

```

## 보여줄 결과

- output/challenge-result.txt: 실제 결과

- review.txt: 새 대화·없는 파일 관찰

- HOW-TO.md: 시작 순서와 오류별 돌아갈 단계

## 복습

같은 규칙과 새 가상 메모로 다시 실행합니다. 발송·메신저·예약을 연결하기 전에 현재 한 작업을 두 번 독립 수행했는지 확인합니다.
