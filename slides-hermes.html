UNDERSTAND / CLASS 04

  • 앱 실행 → 계정 연결 → 짧은 응답 → 실제 파일

UNDERSTAND / CLASS 04

일의 범위를 함께 정해요

  • 읽을 파일, 저장 위치, 바꾸면 안 되는 것을 적습니다. 규칙 파일을 읽으라고 명시하고 결과를 확인합니다. 자연어 규칙은 권한을 기술적으로 차단하는 기능과 같지 않습니다.
  • 읽기: input/ / 저장: output/ / 하지 않을 일: 원문 수정·발송
