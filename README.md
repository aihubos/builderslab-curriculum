# AI Builders Lab · 교육 로드맵

4단계 9개 분반 교육 설계안. HTML·CSS·JavaScript만 사용하는 GitHub Pages 사이트입니다.

- `courses.json`: 분반 목차·대상·준비·결과물 수정
- `template.html`: 페이지 구성 수정
- `style.css`: 반응형 디자인
- `app.js`: 단계 필터와 인쇄 동작
- `python3 build.py`: 데이터 확인 후 index.html 재생성
- `python3 -m http.server 4187`: 로컬 미리보기

기준 자료: 2026-09-21 확인한 https://builderslab.ai-hub-os.com/ 및 기존 교육 자료실의 과정 설계, 사용자가 제공한 AI스터디 4기 분반 미리보기. 원본 문서는 참고 자료로만 사용했으며 운영 규칙이나 검증되지 않은 도구 기능 주장은 옮기지 않았습니다. 신규 분반, 시간과 회차는 제안이며 확정 모집 공고가 아닙니다.
